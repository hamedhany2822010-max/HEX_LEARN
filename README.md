# HEX LEARN

منصة الثقافة المالية لطلاب مدرسة شرويدة الثانوية المشتركة، من إعداد وتطوير Programmer Hamed.

## المتطلبات
- Node.js 18 أو أحدث
- اتصال بالإنترنت أثناء تثبيت الحزم (ليس ضرورياً لتشغيل الإجابات المدمجة بعد التثبيت)

## التشغيل على جهازك
1. فك ضغط الملف.
2. افتح مجلد `hex-learn` في VS Code أو أي محرر.
3. افتح الطرفية داخل المجلد ونفّذ:
   ```bash
   npm install
   ```
4. انسخ `.env.example` وسمّ النسخة `.env`.
5. غيّر `SCHOOL_ACCESS_CODE` إلى كود المدرسة الذي تختاره.
6. شغّل الموقع:
   ```bash
   npm start
   ```
7. افتح `http://localhost:3000`.

## ربط الذكاء الاصطناعي
- ضع مفتاح مزود الذكاء الاصطناعي في `AI_API_KEY` داخل `.env` على الخادم فقط.
- لا تضع المفتاح في `public/app.js` أو أي ملف يصل للمتصفح.
- `AI_MODEL` يحدد اسم النموذج. يمكن ضبط `AI_BASE_URL` لمزود متوافق مع واجهة OpenAI.
- إذا تركت المفتاح فارغاً، تعمل إجابات تعليمية مدمجة محدودة دون استدعاء API.

## ذاكرة الأسئلة المشتركة
- يستخدم المشروع SQLite على الخادم في `data/hex-learn.db`.
- يتم تطبيع السؤال والبحث عن تطابق أو تشابه بسيط قبل استدعاء AI.
- عند العثور على إجابة محفوظة، يعيدها الخادم دون استدعاء AI.
- جميع الطلاب الذين يستخدمون نفس نسخة الخادم وقاعدة البيانات يشتركون في الذاكرة.
- لا تستخدم تخزين المتصفح كبديل لقاعدة البيانات المشتركة.

## قبل نشره للمدرسة
- غيّر كود الدخول الافتراضي.
- استخدم استضافة HTTPS وخادماً دائماً وقاعدة بيانات ذات نسخ احتياطي.
- ضع حدوداً لمعدل الطلبات، وسجلات إدارية، وسياسة خصوصية مناسبة للطلاب.
- احمِ لوحة التحكم إن أضفتها لاحقاً، ولا تعرض مفتاح API للطلاب.
- راجع إجابات الذكاء الاصطناعي التعليمية، ولا تعتمد عليها كنصيحة مالية شخصية.
